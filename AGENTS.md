# A lunar lander game

A simple adaptation of classic Lunar Lander. It should be written in pure JavaScript.

## Screen sizes

it should work on a mobile device as well as laptop.In both cases, the main part of the game screen displays the full height of the game field, There should be a smaller rader screen at bottom right that shows the full height and full width of the game field.

There should be the entire bounded area of  
fixed size. The vertical screen area should be used to show the entire height 
of bounds. The horizontal area that can be displayed depends on the aspect   
ratio. The display has to be clipped, and the radar should show the visible   
area bordered with slightly brighter green.   

## Terrain

Generate a terrain with a seeded random number. That is one can give a seed value to recreate the same terrain.
There are several landing sites.

## Control

We displays two control elements on screen, one is a slider like apperanance, that controls the rotation of the spaceship. Another is a button to use the motor.
